**下载：点下面「Assets」里的 ShiYing-windows-x64.zip**，这就是拾影。「Source code (zip)」「Source code (tar.gz)」是源代码，不用下载。

不知道怎么装？看 [安装方法](https://github.com/Jaqennn/ShiYing#安装)：右键「全部解压缩」，双击 `ShiYing.exe`，第一次打开点「一键安装」。也可以让 AI 帮你装。

需要 Windows 10 或 Windows 11（64 位）。弹出「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」（拾影没有买数字签名证书）。

## 拾影能做什么

- 免费、开源，没有广告，不用注册账号
- 粘贴链接就能下载，按使用人数排：微信公众号文章里的视频、抖音（无水印，图集下原图）、哔哩哔哩、YouTube、X（Twitter），以及 yt-dlp 支持的 1700 多个网站
- 第一次打开自动弹出安装向导，一键装好需要的组件，有总进度条、速度和剩余时间；国内下载慢可以一键换加速镜像，下完和官方校验值核对
- 多线程加速下载：每个文件 16 个连接同时下
- AI 中文字幕：在你电脑上识别英文语音，用 DeepL 或大模型翻译，生成和视频同名的中文、中英双语字幕，PotPlayer 自动加载
- 打开时自动检查 yt-dlp 更新，网站改版后一般很快就能恢复

## 从旧版本升级

关掉拾影，把新的压缩包解压后覆盖原来的 `ShiYing` 文件夹。设置、下载记录、组件和模型都不在这个文件夹里，不会丢，也不用重装组件。

## 反馈

软件右上角点「反馈」：会列出你的系统、拾影和各组件的版本，点「复制这些信息」，或者直接点「去 GitHub 反馈」。下载失败的任务旁边也有「反馈」，会顺带填好出错的网站和错误提示。能用、不能用都欢迎反馈。
